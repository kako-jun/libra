# Libra — 機能一覧

## 緊急メッセージ

- 来てください
- 苦しい
- 痛い
- 水
- 体位を変えたい
- はい
- いいえ

1タップで画面上部に大きく表示する。

## ゆっくり伝える

- 痛い場所
- 困りごと
- 気分
- 家族に伝える
- 文字盤

深い操作は緊急導線から分離する。

## 自動スキャン

画面を見るだけ、または外部ボタン1つだけで選択できるようにする。

プロトタイプでは Space / Enter を決定操作にしている。Bluetooth シャッターボタンはこの入力に寄せる。

## 音声モード

- OFF
- 効果音だけ
- 短く読む
- 全部読む

相部屋や夜間に配慮し、デフォルトは OFF 寄りにする。
