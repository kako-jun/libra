# Libra — 機能一覧

詳細・優先順位の正本は `requirements.md`。

## 緊急

- 選択した瞬間に「緊急です。来てください」を赤で大きく表示し、警告音を鳴らす（音声 OFF でも鳴る）
- 確認手順なし。介助者が解除するまで表示が残る
- 任意で詳細: 苦しい / 痛い / 息ができない / 吐きそう / 胸が痛い

## はい / いいえ

ホームで緊急の次に置く。質問への応答が最も頻度が高い。

## 不快

痛い（場所）/ 苦しい / 痰 / 体の向き / 暑い / 寒い / トイレ / 喉が渇いた / かゆい / 眠れない

## 快・要望

大丈夫 / ありがとう / 眠りたい / 静かにしてほしい / 家族に会いたい / 話したい / テレビ・音楽

## 文字盤

最後の手段。清音 46 字 + 「ー」。行 → 文字の2段階スキャン。入力途中の文字列を常に大きく表示し、周囲の先読みを「はい / いいえ」で受ける。

## シングルスイッチ自動スキャン

- 起動時から常時動作。本人の入力は「オン」1種類だけ
- タップ / 任意キー / Bluetooth シャッターを同じオンとして扱う
- スキャン間隔・先頭待機・連打無視・聴覚スキャンを介助者が設定（localStorage 保存）

## 音声モード

- OFF
- 効果音だけ
- 短く読む
- 全部読む

相部屋や夜間に配慮し、デフォルトは OFF。ただし緊急の警告音は OFF でも鳴らす。
