# Libra — 使い方ガイド

## 起動

ブラウザで Libra を開く。すぐに自動スキャンが始まり、カーソルが項目を順に巡る。画面上部には、いま相手へ見せるメッセージが大きく表示される。

常設して使う場合は、ホーム画面に追加して開く（全画面で起動する）・端末の自動ロックを OFF にする・充電しながら使うことを推奨する。ネットワークが切れたりバックエンドが止まっても、緊急・はい/いいえ等の伝達はオフラインのまま動き続ける。

## 本人の操作

カーソルが伝えたい項目に来たら、スイッチを1回押す。操作はこれだけ。

- スイッチ: 任意のキー / Bluetooth シャッターボタン（カーソルが乗っている項目を実行）
- 直接タップ: 選びたいタイルを直接タップ（カーソルの位置に関係なく、そのタイルを実行）。画面の背景（タイルの外）をタップしても何も起きない
- ホームの先頭項目は「緊急」。通常の下位画面は「戻る」「緊急」の順で、緊急詳細は「戻る」が先頭（重複する緊急タイルなし）
- ホームの順番: 緊急 → はい → いいえ → 不快 → 快・要望 → 文字盤
- 下位画面へ進むタイル（不快・快・要望・文字盤など）には右端に山形アイコン、下部に中身の予告（例:「痛い・苦しい・…」）が出る
- 痛い場所を選ぶと、続けて強さ（場所だけ / 少し / かなり / とても）を選ぶ。快・要望は「続けて・やめて・もっと・変えて」が最上位で、要望と気分はその下の画面にある
- 下の画面から戻るときは先頭の「戻る」を選ぶ。親画面へ戻っても、介助者が解除するまでは緊急表示が残る
- 画面上部のメッセージ欄には、いま伝えている内容だけが出る。1 行に収まる長さなら改行せず、収まる最大の大きさで表示される（長い文だけ折り返す）。アプリ名や音声モード、スキャン位置は表示しない（自分の位置はスキャン中のタイルの強調で分かる）
- 何かを伝えた直後の1周だけ、ホームの緊急の次に「取り消し」が出る。選ぶと直前の表示に1つ戻せる。何もしないまま1周過ぎると自然に消える（緊急中は出ない）

- 画面の一番下に、いま効いている「自動で起きること」が常に出る（隠せない。画面を見る人向けで、聴覚スキャンの読み上げ対象ではない）。出るのは該当するときだけ。
  - 取り消しは伝えた直後の1周だけ出る。緊急中は出ない。
  - 緊急中は3秒ごとに振動する（端末が振動できて、介助者の設定で振動が ON のとき。本人の入力直後は休む）。振動できない端末では「この端末は振動できません（緊急中の周期振動なし）」と出る（緊急の読み上げや効果音は音声モードに従って別に出る）。再起動後は画面に触れるかキーを押すまで振動しない旨も出る。
  - 連打無視（画面が変わった直後も効く）・押下時間の下限・離して決定の設定があるときは、押しても反応しないことがある旨と理由、押している間に画面や項目の並びが変わると無効になる旨。
  - 聴覚スキャン ON で音声モードが「短く」「全部」のときは、伝達の読み上げは直後の1項目分だけ割り込まれないこと。
  - スキャン開始時に先頭に留まる秒数。
  - 設定が無効なら該当の文は出ない。秒数は介助者の設定に追従する。低い・狭い画面では短い文言になる。

## モールス入力（上級者向け）

介助者が設定の「入力方式」で「モールス入力を使う」をONにすると、ホームの最後に「モールス」が出る。短く押す＝短点（・）、長く押す＝長点（－）（境目の秒数は画面に出る）で、和文モールスで文字を入力する。

- 緊急は **SOS（・・・ －－－ ・・・）を休まず続けて**打つ。9つ目の押下を離した時点で、待たずにすぐ緊急になる。前に間違えた押下があっても、休まず続ければ緊急になる。文字の確定時間（既定 1.5 秒）休むと数え直しになり、文字ごとに休んで打った SOS は緊急にならない（「かぜ」など、かなを打った結果が偶然 SOS の並びになるだけでは緊急にしないため）
- ・を5つ → 待つとスキャンへ戻る。・を6つ → 待つと1字消す。・－・－・－ → 待つと確定して伝える
- 押下と解放をほぼ同時に送る Bluetooth シャッターでは長押しを区別できず、モールスも SOS も使えない場合がある。その場合はモールスを使わず、スキャンを使う
- 画面の案内の見方: 操作の符号と、時間で自動で起きること（文字が決まるまで・語の区切りまで・何も押さないとスキャンへ戻るまで・押しっぱなしの無効）が常に表示される。秒数は介助者の設定に合わせて変わる。押下時間の下限を設定している場合は「◯秒未満の押下は数えない」も出る

## 介助者の操作

画面上部の案内欄（現在地・画面の案内）の右上にある「介助者用」ボタンを通常のクリック/タップで開くと、設定と緊急解除ができる。上部のカテゴリタブ（状態 / スキャン / 入力方式 / フィードバック / 表示 / フレーズ / データ）で設定を切り替える。フレーズ編集は「フレーズ」、設定の書き出し・取り込み・既定に戻すは「データ」タブにある。ボタンにフォーカスした Enter / Space でも開く。この入口は本人のスキャン決定とは別で、介助者メニューはタッチで操作する（メニュー中のキー入力はメニューを閉じる。例外は、タブにフォーカス中の ←/→/Home/End（修飾キーなし）と、フレーズ編集欄での文字入力の打鍵）。

- スキャン間隔 / 先頭待機 / 連打無視 / 聴覚スキャン / 音声モード
- 文字サイズ（標準 / 大 / 特大）: 選択肢（タイル）の文字を、そのタイルに収まる範囲で段階的に大きくする。メッセージ欄の見出しの大きさはこの設定に左右されない（見出しが伸縮すると格子の面積が変わり、結果的にタイルの文字が逆に縮むことがあったため）。画面のレイアウト（列数・タイルの配置・大きさ）自体は変わらない。選択肢が少ない画面でも、タイルは大きくならず同じ大きさのまま空いたマスが残る（空きマスは選べない）
- 表示（明るい / 夜間 / 自動、既定 自動）: 昼夜で画面の明暗を切り替える。「自動」は端末の設定（prefers-color-scheme）にその場で追従する
- 高コントラスト（ON / OFF）: 明るい・夜間どちらの表示の上にも重ねて効く。文字と面の明暗差を強め、タイル間の区切り線を太くする
- 「画面スリープ防止」の状態表示。「有効」なら画面消灯を防げている。「無効」の場合は端末の自動ロックを OFF にする（`docs/troubleshooting.md` 参照）
- 「全画面にする」（対応環境のみ表示）。ブラウザの UI を隠し、常設運用時の誤操作を減らせる
- 緊急表示は介助者が解除するまで残る。緊急警告音は鳴らさない。再読み込み・再起動しても解除まで復元される
- メニュー表示中は本人のスイッチ入力が働かない。以下のいずれでも、その操作自体では何も実行せずメニューが閉じてホーム先頭からスキャンが再開する
  - 無操作のまま 60 秒経過する（メニュー上部の帯に常時書いてある。延ばせるのはパネル内のタップだけで、キー入力では延びない。同じ帯に、外側のタップ・キー入力でも閉じること（入力欄・スライダー・チェックボックス操作中の文字/矢印/Home/End キーと、タブ上の ←/→/Home/End は閉じない）、メニューを開いている間はスキャン（モールス入力が有効ならモールス入力の時間も）が止まることも書いてある）
  - 本人が誤ってキーを押す（keydown）。ただしタブにフォーカス中の ←/→/Home/End（修飾キーなし）と、入力欄・スライダー・チェックボックスにフォーカス中の文字入力・Backspace・矢印・Home/End・IME変換中の打鍵は閉じない（スライダー上で矢印キー型のスイッチを押すと設定値が静かに変わりうる）（どちらも60秒タイマーは延ばさない）
  - メニューパネルの外側（背景）をタップする
  - パネル内の操作は通常の介助者操作として扱われる（閉じない）
