# Libra — 使い方ガイド

## 起動

ブラウザで Libra を開く。画面上部に、いま相手へ見せるメッセージが大きく表示される。

## 基本操作

- タイルを押すと、その内容が大きく表示される
- 「いそいで伝える」は緊急の短い用件
- 「ゆっくり伝える」は痛い場所・困りごと・気分・文字盤
- 「音声」で読み上げ方法を切り替える
- 「スキャン開始」で自動選択を開始する

## キーボード / 外部ボタン

| 入力 | 動作 |
|---|---|
| `1`-`9` | 先頭9タイルを直接実行 |
| 矢印キー | スキャン対象を移動 |
| `Space` / `Enter` | スキャン対象を実行 |
| `Escape` | 戻る |

Bluetooth シャッターボタンは、最終的に Space / Enter 相当の入力として扱う想定。
