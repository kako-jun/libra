# Libra — 使い方ガイド

## 起動

ブラウザで Libra を開く。すぐに自動スキャンが始まり、カーソルが項目を順に巡る。画面上部には、いま相手へ見せるメッセージが大きく表示される。

## 本人の操作

カーソルが伝えたい項目に来たら、スイッチを1回押す。操作はこれだけ。

- スイッチ: 画面のどこかをタップ / 任意のキー / Bluetooth シャッターボタン
- 各画面の最初の項目は「緊急」
- ホームの順番: 緊急 → はい → いいえ → 不快 → 快・要望 → 文字盤
- 下の画面から戻るときは「戻る」を選ぶ

## 介助者の操作

画面隅の介助者ボタンを 2 秒長押しすると、設定と緊急解除ができる。

- スキャン間隔 / 先頭待機 / 連打無視 / 聴覚スキャン / 音声モード
- 緊急表示は介助者が解除するまで残る。警告音は音声 OFF でも鳴る
