# Libra — 使い方ガイド

## 起動

ブラウザで Libra を開く。すぐに自動スキャンが始まり、カーソルが項目を順に巡る。画面上部には、いま相手へ見せるメッセージが大きく表示される。

常設して使う場合は、ホーム画面に追加（インストール）して開く（全画面で起動する）・端末の自動ロックを OFF にする・充電しながら使うことを推奨する。アプリ内に「全画面にする」ボタンはない（Issue #119）ので、ブラウザの UI を隠したいときはホーム画面に追加して開く。ネットワークが切れたりバックエンドが止まっても、緊急・はい/いいえ等の伝達はオフラインのまま動き続ける。

## 本人の操作

カーソルが伝えたい項目に来たら、スイッチを1回押す。操作はこれだけ。

- スイッチ: 任意のキー / Bluetooth シャッターボタン（カーソルが乗っている項目を実行）
- 直接タップ: 選びたいタイルを直接タップ（カーソルの位置に関係なく、そのタイルを実行）。
- ボタン以外を押す: パネル・ボタン・矢印・パンくずのリンク以外の場所（空きマス・伝達欄・画面の案内など）をどこでも押すと、黄色のパネルを選ぶ（キーと同じ。押下時間の下限・決定のタイミング・連打無視も同じように効き、押し始めの黄色を選ぶ）。指示文の近くに「ボタン以外を押すと、黄色を選びます」と出る。介助者用メニューを開いている間は選ばない。画面を拭く・持ち直すなどで触れても選ぶことがある。**読み込み直後と、介助者が介助者用メニューを閉じた直後は、黄色が先頭の「緊急」にあるので、背景に触れると緊急を選ぶ**（先頭にとどまるのは既定で 2.0 秒）
- 複数の指・手のひら: 指などが画面に触れたままの間は、後から背景に触れても何もしない。背景を押している間に触れたパネルも実行しない。手が画面に置かれたままだと背景は反応しない（10 秒を超えると、次の接触は数える）
- ホームの先頭項目は「緊急」。通常の下位画面は「戻る」「緊急」の順で、緊急詳細は「戻る」が先頭（重複する緊急タイルなし）
- 押すと「直前に伝えたこと」の欄が赤くなるパネル（「苦しい」、痛みの強さの「とても」など）は、ほかと違う赤みのある色です。「胸」のように次の画面へ進むだけのパネルと「緊急」は色が変わりません
- ホームの順番: 緊急 → もう一度 → はい → いいえ → 快 → 不快 → 要望 → 文字盤（モールス入力をONにしたときだけ最後に「モールス」が加わる）。ホームは 8 項目で、下位画面と同じ 8 セルの格子（縦長は 2列×4行、横長は 4列×2行）に空きなく並ぶ。モールス入力をONにすると 9 項目になり、10 セル（縦長は 5段、横長は 5列。空き 1 マス）になって、パネルは少し小さくなる。文字盤の行を選ぶ画面は 15 セル。「はい」と「いいえ」は、どの画面でも同じ段で左右に並ぶ。ホームの全項目と「戻る」には、意味を示す小さな絵（アイコン）が付く（文字は変わらない）
- 下位画面へ進むタイル（快・不快・要望・文字盤など）には右端に山形アイコン、下部に中身の予告（例: 文字盤は「あ行・か行・さ行・た行・な行・は行…」、快は「続けて・やめて・変えて・気分」）が出る（遷移先が6項目以下なら全項目、7項目以上なら先頭6項目の後ろに「…」。セルに余裕があれば2行まで、狭いときは1行で末尾が省略される。項目の途中で折り返すことがある）
- 痛い場所を選ぶと、続けて強さ（場所だけ / 少し / かなり / とても）を選ぶ。快は「続けて・やめて・変えて」が最上位で、気分はその下の画面にある。要望はホームから直接開く
- 「もう一度」: 聞き逃されたときに、直前に伝えたことをもう一度伝える（振動・読み上げ・表示の点滅）。選んだ選択をやり直さなくてよい。まだ何も伝えていないときは、押しても何も伝えない（項目は薄く表示される）。緊急中で伝達が無いときは、緊急の呼び出しをもう一度伝える
- 下の画面から戻るときは先頭の「戻る」を選ぶ。親画面へ戻っても、緊急表示は残る。緊急を解除するのは、介助者がメニューで解除するか、本人が 緊急 → 緊急を解除 → 解除する を選んだとき（「緊急を解除」は緊急詳細の一番最後。確認画面の先頭は「戻る」なので、続けて押しても解除されない。無入力のまま 3 周するとホームへ戻り、緊急は残る）。解除すると、振動（長め 1 回）と解除の文（選んだ詳細を含む。例「緊急（息ができない）を解除しました。」）の表示・読み上げで知らせる。緊急と詳細は伝達の履歴に残るので、後から来た介助者は枠の矢印で振り返れる
- 画面上部には、上から 緊急の表示 → 「直前に伝えたこと」 → 現在地・画面の案内 の順に出る。「直前に伝えたこと」には、いま伝えている内容だけが出る。この枠は起動時から出ていて（何も伝えていないときは「いまは、伝えたことがありません。」）、高さは内容で変わらないので、下のタイルは動かない。1 行に収まる長さなら改行せず、収まる最大の大きさで表示される（長い文は折り返し、文字を小さくして全文を枠に収める）。アプリ名や音声モード、スキャン位置は表示しない（自分の位置はスキャン中のタイルの強調で分かる）。現在地の先頭「ホーム」には家のアイコンが付く
- 介助者は、「直前に伝えたこと」の枠の左右の矢印（タップ / クリックだけ。本人のスイッチでは動かない）で、過去の伝達を振り返れる。矢印はその方向に内容があるときだけ出る（矢印を続けて押して端まで来ても、消えた矢印の場所では何も起きない）。背景色はその内容の色で、赤で出た内容は過去の表示でも赤になる（「過去に伝えたこと（N件前）」。最大 50 件。端末のメモリ内だけで、再読み込みすると消える）。新しい伝達・緊急で最新の表示に戻る。起動直後や緊急を介助者が解除した直後など最新が空のときは「いまは、伝えたことがありません。」と出る
- ホーム以外の画面（モールス入力を除く）で、入力がないままカーソルが3周ぶん進むと、自動でホームに戻る（途中で入力したら、そこから数え直す。ボタンやキーを押している間は数えない）。戻っても緊急表示・伝えた内容・文字盤の入力途中の文字列（文字盤を開き直すと残っている）は残る。この自動復帰の説明は画面には出ない

- 本人画面の一番下に出る常時案内は、緊急中の振動のものだけ（隠せない。画面を見る人向けで、聴覚スキャンの読み上げ対象ではない）。緊急でないときは何も出ない。画面を見れば分かること（スキャン開始時に先頭にとどまること）は、どこにも案内を出さない。
  - 緊急中は3秒ごとに振動する（端末が振動できて、介助者の設定で振動が ON のとき。本人の入力直後は休む）。「緊急中は3秒ごとに振動します。」と出る。振動できない端末では「この端末は振動できません。」と出る（緊急の読み上げや効果音は音声モードに従って別に出る）。再起動後は画面に触れるかキーを押すまで振動しないので、「画面に触れるかキーを押すと、振動を再開します。」も出る。
  - 設定が無効なら該当の文は出ない。秒数は介助者の設定に追従する。低い・狭い画面では短い文言になる。
- 見ても分からない、設定に応じた動作は、介助者用メニューの「スキャン」タブで、原因の設定のすぐ下に出る（現在の設定値で出し分け。該当がなければ何も出ない）。連打無視（画面が変わった直後も効く）・押下時間の下限・離して決定の設定があるときは、押しても反応しないことがある旨と、押している間に画面や項目の並びが変わると無効になる旨。聴覚スキャン ON で音声モードが「短く」「全部」のときは、伝達の読み上げは直後の1項目分だけ割り込まれないこと。

## モールス入力（上級者向け）

介助者が設定の「モールス」タブで「モールス入力を使う」をONにすると、ホームの最後に「モールス」が出る。短く押す＝短点（・）、長く押す＝長点（－）（境目の秒数は画面に出る）で、和文モールスで文字を入力する。キー / スイッチのほか、画面のボタン以外の場所を押しても同じように入力できる。

- 緊急は **SOS（・・・ －－－ ・・・）を休まず続けて**打つ。9つ目の押下を離した時点で、待たずにすぐ緊急になる。前に間違えた押下があっても、休まず続ければ緊急になる。文字の確定時間（既定 1.5 秒）休むと数え直しになり、文字ごとに休んで打った SOS は緊急にならない（「かぜ」など、かなを打った結果が偶然 SOS の並びになるだけでは緊急にしないため）
- ・を5つ → 待つとスキャンへ戻る。・を6つ → 待つと1字消す。・－・－・－ → 待つと確定して伝える
- 押下と解放をほぼ同時に送る Bluetooth シャッターでは長押しを区別できず、モールスも SOS も使えない場合がある。その場合はモールスを使わず、スキャンを使う
- 画面の案内の見方: 操作の符号と、時間で自動で起きること（文字が決まるまで・語の区切りまで・何も押さないとスキャンへ戻るまで・押しっぱなしの無効）が常に表示される。秒数は介助者の設定に合わせて変わる。押下時間の下限を設定している場合は「◯秒未満の押下は数えない」も出る

## 介助者の操作

画面上部の案内欄（現在地・画面の案内）の右上にある「介助者用」ボタン（左に、設定した好きな画像が出ることがある）を通常のクリック/タップで開くと、設定と緊急解除ができる。メニューを閉じるボタン（「閉じる」）は、どの画面の大きさでも画面の右上にある。「緊急を解除」は緊急中だけ、左右の中央に出る（狭い画面では「閉じる」の下の行）。上部のカテゴリタブ（使用準備 / スキャン / 音と振動 / 表示 / フレーズ / モールス / データ / このアプリ。タブが画面に収まらないときは、続きがある側に矢印が出る）で設定を切り替える。フレーズ編集は「フレーズ」、設定の書き出し・取り込みは「データ」、使い方・リンク・利用回数・バージョンは「このアプリ」タブにある。ボタンにフォーカスした Enter / Space でも開く。この入口は本人のスキャン決定とは別で、介助者用メニューはタッチで操作する（メニュー中のキー入力はメニューを閉じる。例外は、タブにフォーカス中の ←/→/Home/End（修飾キーなし）と、フレーズ編集欄での文字入力の打鍵）。

- スキャン間隔 / 先頭待機（スキャン開始時に先頭に留まる秒数。既定は間隔 1.5 秒のとき 2.0 秒。設定画面に秒数が出る。すでに保存した設定はそのままで、「スキャン」タブの「初期値に戻す」で新しい既定になる）/ 連打無視（0.1〜3 秒。0 にはできない） / 押下時間の下限 / 決定のタイミング / 聴覚スキャン（スキャンタブ）、モールス入力（モールスタブ）、音声モード / 振動（音と振動タブ）。スライダーは左右の矢印で 1 段階ずつ調整できる（端まで来ると外側の矢印は消える）
- 文字サイズ（標準 / 大 / 特大。すぐ下のサンプルで大きさを確かめられる）: 選択肢（タイル）の文字を、そのタイルに収まる範囲で段階的に大きくする。メッセージ欄の見出しの大きさはこの設定に左右されない（見出しが伸縮すると格子の面積が変わり、結果的にタイルの文字が逆に縮むことがあったため）。画面のレイアウト（列数・タイルの配置・大きさ）自体は変わらない。選択肢が少ない画面でも、タイルは大きくならず同じ大きさのまま空いたマスが残る（空きマスは選べない）。「直前に伝えたこと」やパンくずなどの補助文字は、この設定にかかわらず常に 16px 以上で表示する（この設定ではまだ大きくならない）
- 明るさ（明るい / 夜間 / 自動、既定 自動）: 昼夜で画面の明暗を切り替える。「自動」は端末の設定（prefers-color-scheme）にその場で追従する
- 高コントラスト（ON / OFF）: 明るい・夜間どちらの表示の上にも重ねて効く。文字と面の明暗差を強め、タイル間の区切り線を太くする
- 「使用準備」タブ（メニューを開くと最初に出る。変える設定はない）の「画面スリープ防止」の状態表示。「有効」なら画面消灯を防げている。「無効」の場合は端末の自動ロックを OFF にする（`docs/troubleshooting.md` 参照）
- アプリのインストール（使用準備タブ）: ブラウザが受け付ける場合は「アプリをインストール」ボタンから端末の確認画面を出せる。iPhone / iPad や Mac の Safari などボタンから出せない場合は、手順が箇条書きで出る（デスクトップの Firefox では、Chrome か Edge で開くよう案内する）。インストールした版で開くと「アプリはインストール済みです。」と出る（Android と iOS の実機でのインストールは未確認）
- 好きな画像（表示タブ。Issue #122）: 「画像を選ぶ」で端末の画像を 1 枚選ぶと、本人画面の「介助者用」ボタンの左に表示される（押すと、ボタン以外の場所と同じく黄色のパネルを選ぶ）。長辺 480px に縮小して、この端末の中（localStorage の `libra:photo`）だけに保存し、外へは送らない。設定の書き出しには含まれない。「画像を消す」か、表示タブの「初期値に戻す」で消える
- 初期値に戻す（スキャン / モールス / 音と振動 / 表示 / フレーズの各タブの末尾。Issue #117）: そのタブの設定だけを初期値に戻す。1 回目に押すと何が戻るかが出て、もう一度押すと実行する（「やめる」・タブの切替・メニューを閉じるで取りやめ）。緊急状態と本人のスキャンには影響しない
- 「このアプリ」タブ（Issue #118）: 使い方・「くわしい使い方」（このガイド）・ご意見・ご感想の掲示板・作者サイトへのリンク、利用回数、バージョン（`package.json` の version とビルド日）。利用回数は、本番のサイトで開いたときだけ、起動ごとに 1 回数える（同じ端末の重複は 1 日単位で除かれる）。通信できないときは「取得できません」と出るだけで、伝達には影響しない。リンクは別の画面（ブラウザ）で開くので、通信が必要。インストールしたアプリから開いた場合、リンク先を開いている間は本人のスイッチ操作も画面の自動消灯の防止も効かないので、見終わったら必ずアプリの画面に戻る
- 緊急表示は、介助者が解除するか、本人が 緊急 → 緊急を解除 → 解除する を選ぶまで残る。緊急警告音は鳴らさない。再読み込み・再起動しても解除まで復元される
- メニュー表示中は本人のスイッチ入力が働かない。以下のいずれでも、その操作自体では何も実行せずメニューが閉じてホーム先頭からスキャンが再開する
  - 無操作のまま 60 秒経過する（延ばせるのはパネル内のタップだけで、キー入力では延びない。矢印ボタンのタップも延びる。画面には説明の文は出ない）。メニューを開いている間はスキャン（モールス入力が有効ならモールス入力の時間も）が止まる
  - 本人が誤ってキーを押す（keydown）。ただしタブにフォーカス中の ←/→/Home/End（修飾キーなし）と、入力欄・スライダー・チェックボックスにフォーカス中の文字入力・Backspace・矢印・Home/End・IME変換中の打鍵は閉じない（スライダー上で矢印キー型のスイッチを押すと設定値が静かに変わりうる）（どちらも60秒タイマーは延ばさない）
  - パネル内の操作は通常の介助者操作として扱われる（閉じない）
