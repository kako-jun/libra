# Libra — 使い方ガイド

## 起動

ブラウザで Libra を開く。すぐに自動スキャンが始まり、カーソルが項目を順に巡る。画面上部には、いま相手へ見せるメッセージが大きく表示される。

起動直後はブラウザの自動再生制限により警告音がまだ鳴らせる状態になっていない。画面かキーに最初に触れるまで「警告音停止中：画面をタップしてください」と画面隅に出る。

常設して使う場合は、ホーム画面に追加して開く（全画面で起動する）・端末の自動ロックを OFF にする・充電しながら使うことを推奨する。ネットワークが切れたりバックエンドが止まっても、緊急・はい/いいえ等の伝達はオフラインのまま動き続ける。

## 本人の操作

カーソルが伝えたい項目に来たら、スイッチを1回押す。操作はこれだけ。

- スイッチ: 画面のどこかをタップ / 任意のキー / Bluetooth シャッターボタン
- 各画面の最初の項目は「緊急」
- ホームの順番: 緊急 → はい → いいえ → 不快 → 快・要望 → 文字盤
- 下位画面へ進むタイル（不快・快・要望・文字盤など）には右端に山形アイコン、下部に中身の予告（例:「痛い・苦しい・…」）が出る
- 下の画面から戻るときは「戻る」を選ぶ
- 画面上部のメッセージ欄には、いま伝えている内容だけが出る。アプリ名や音声モード、スキャン位置は表示しない（自分の位置はスキャン中のタイルの強調で分かる）
- 何かを伝えた直後の1周だけ、ホームの緊急の次に「取り消し」が出る。選ぶと直前の表示に1つ戻せる。何もしないまま1周過ぎると自然に消える（緊急中は出ない）

## 介助者の操作

画面隅の介助者ボタンを 2 秒長押しすると、設定と緊急解除ができる。介助者メニューはタッチで操作する（メニュー中のキー入力はメニューを閉じる）。

- スキャン間隔 / 先頭待機 / 連打無視 / 聴覚スキャン / 音声モード
- 文字サイズ（標準 / 大 / 特大）: 見出し・タイルの文字を一段階ずつ拡大する。画面全体のレイアウトはそのまま維持される
- 高コントラスト（ON / OFF）: 明るい案・暗い案どちらの上にも重ねて効く。文字と面の明暗差を強め、タイル間の区切り線を太くする
- 「画面スリープ防止」の状態表示。「有効」なら画面消灯を防げている。「無効」の場合は端末の自動ロックを OFF にする（`docs/troubleshooting.md` 参照）
- 「全画面にする」（対応環境のみ表示）。ブラウザの UI を隠し、常設運用時の誤操作を減らせる
- 緊急表示は介助者が解除するまで残る。警告音は音声 OFF でも鳴る
- メニュー表示中は本人のスイッチ入力が働かない。以下のいずれでも、その操作自体では何も実行せずメニューが閉じてホーム先頭からスキャンが再開する
  - 無操作のまま 60 秒経過する
  - 本人が誤ってキーを押す（keydown）
  - メニューパネルの外側（背景）をタップする
  - パネル内の操作は通常の介助者操作として扱われる（閉じない）
