# Libra — 使い方ガイド

## 起動

ブラウザで Libra を開く。すぐに自動スキャンが始まり、カーソルが項目を順に巡る。画面上部には、いま相手へ見せるメッセージが大きく表示される。

常設して使う場合は、ホーム画面に追加してインストールし、全画面で開く・端末の自動ロックを OFF にする・充電しながら使うことを推奨する。アプリ内に「全画面にする」ボタンはないので、ブラウザの UI を隠したいときはホーム画面に追加して開く。ネットワークが切れたりバックエンドが止まっても、緊急・はい/いいえ等の伝達はオフラインのまま動き続ける。

## 本人の操作

カーソルが伝えたい項目に来たら、スイッチを1回押す。操作はこれだけ。

- スイッチ: 任意のキー / Bluetooth シャッターボタン。カーソルが乗っている項目を実行する
- 直接タップ: 選びたいパネルを直接タップする。カーソルの位置に関係なく、そのパネルを実行する。
- ボタン以外を押す: パネル・ボタン・矢印・パンくずのリンク以外の場所なら、空きマス・伝達欄・画面の案内などどこを押しても、黄色のパネルを選ぶ。キーと同じで、押下時間の下限・決定のタイミング・連打無視も同じように効き、押し始めの黄色を選ぶ。指示文の近くに「ボタン以外を押すと、黄色を選びます」と出る。介助者用メニューを開いている間は選ばない。画面を拭く・持ち直すなどで触れても選ぶことがある。**読み込み直後と、介助者が介助者用メニューを閉じた直後は、黄色が先頭の「緊急」にあるので、背景に触れると緊急を選ぶ**。先頭にとどまるのは既定で 2.0 秒
- 複数の指・手のひら: 指などが画面に触れたままの間は、後から背景に触れても何もしない。背景を押している間に触れたパネルも実行しない。手が画面に置かれたままだと背景は反応しない。10 秒を超えると、次の接触は数える
- ホームの先頭項目は「緊急」。通常の下位画面は「戻る」「緊急」の順で、緊急詳細は「戻る」が先頭で、重複する緊急パネルは置かない
- 押すと「直前に伝えたこと」の欄が赤くなるパネル、たとえば「苦しい」や痛みの強さの「とても」は、ほかと違う赤みのある色です。「胸」のように次の画面へ進むだけのパネルと「緊急」は色が変わりません
- ホームの順番: 緊急 → もう一度 → はい → いいえ → 快 → 不快 → 要望 → 文字盤。モールス入力をONにしたときだけ、最後に「モールス」が加わる。ホームは 8 項目で、下位画面と同じ 8 セルの格子に空きなく並ぶ。縦長は 2列×4行、横長は 4列×2行。モールス入力をONにすると 9 項目になり、10 セルになって、縦長は 5段、横長は 5列で空きが 1 マスできる。パネルは少し小さくなる。文字盤の行を選ぶ画面は 15 セル。「はい」と「いいえ」は、どの画面でも同じ段で左右に並ぶ。ホームの全項目と「戻る」には、意味を示す小さな絵のアイコンが付く。文字は変わらない
- 快・不快・要望・文字盤など、下位画面へ進むパネルには右端に山形アイコン、下部に中身の予告が出る。たとえば文字盤は「あ行・か行・さ行・た行・な行・は行…」、快は「続けて・やめて・変えて・気分」となる。遷移先が6項目以下なら全項目、7項目以上なら先頭6項目の後ろに「…」が付く。セルに余裕があれば2行まで、狭いときは1行で末尾が省略される。項目の途中で折り返すことがある。
- 痛い場所を選ぶと、続けて強さを、場所だけ / 少し / かなり / とても から選ぶ。快は「続けて・やめて・変えて」が最上位で、気分はその下の画面にある。要望はホームから直接開く
- 「もう一度」: 聞き逃されたときに、直前に伝えたことを振動・読み上げ・表示の点滅でもう一度伝える。選んだ選択をやり直さなくてよい。まだ何も伝えていないときは、押しても何も伝えない。項目は薄く表示される。緊急中で伝達が無いときは、緊急の呼び出しをもう一度伝える
- 下の画面から戻るときは先頭の「戻る」を選ぶ。親画面へ戻っても、緊急表示は残る。緊急を解除するのは、介助者がメニューで解除するか、本人が 緊急 → 緊急を解除 → 解除する を選んだとき。「緊急を解除」は緊急詳細の一番最後にある。確認画面の先頭は「戻る」なので、続けて押しても解除されない。無入力のまま 3 周するとホームへ戻り、緊急は残る。解除すると、長め 1 回の振動と、解除の文の表示・読み上げで知らせる。解除の文は選んだ詳細を含み、たとえば「「息ができない」の緊急を解除しました。」となる。緊急と詳細は伝達の履歴に残るので、後から来た介助者は枠の矢印で振り返れる
- 画面上部には、上から 緊急の表示 → 「直前に伝えたこと」 → 現在地・画面の案内 の順に出る。「直前に伝えたこと」には、いま伝えている内容だけが出る。この枠は起動時から出ていて、何も伝えていないときは「いまは、伝えたことがありません。」と出る。高さは内容で変わらないので、下のパネルは動かない。1 行に収まる長さなら改行せず、収まる最大の大きさで表示される。長い文は折り返し、文字を小さくして全文を枠に収める。アプリ名や音声モード、スキャン位置は表示しない。自分の位置はスキャン中のパネルの強調で分かる。現在地の先頭「ホーム」には家のアイコンが付く
- 介助者は、「直前に伝えたこと」の枠の左右の矢印で、過去の伝達を振り返れる。矢印はタップ / クリックだけで動き、本人のスイッチでは動かない。その方向に内容があるときだけ出る。矢印を続けて押して端まで来ても、消えた矢印の場所では何も起きない。背景色はその内容の色で、赤で出た内容は過去の表示でも赤になる。過去を表示している間の見出しは「N件前に伝えたこと」。振り返れるのは最大 50 件で、端末のメモリ内だけに持ち、再読み込みすると消える。新しい伝達・緊急で最新の表示に戻る。起動直後や緊急を介助者が解除した直後など最新が空のときは「いまは、伝えたことがありません。」と出る
- モールス入力を除くホーム以外の画面で、入力がないままカーソルが3周ぶん進むと、自動でホームに戻る。途中で入力したら、そこから数え直す。ボタンやキーを押している間は数えない。戻っても緊急表示・伝えた内容・文字盤の入力途中の文字列は残り、文字盤を開き直すと入力途中の文字列がある。この自動復帰の説明は画面には出ない

- 本人画面の一番下に出る常時案内は、緊急中の振動のものだけ。隠せない。画面を見る人向けで、聴覚スキャンの読み上げ対象ではない。緊急でないときは何も出ない。スキャン開始時に先頭にとどまることのように、画面を見れば分かることは、どこにも案内を出さない。
  - 端末が振動できて、介助者の設定で振動が ON のときは、緊急中は3秒ごとに振動する。本人の入力直後は休む。「緊急中は3秒ごとに振動します。」と出る。振動できない端末では「この端末は振動できません。」と出る緊急の読み上げや効果音は、音声モードに従って別に出る。再起動後は画面に触れるかキーを押すまで振動しないので、「画面に触れるかキーを押すと、振動を再開します。」も出る。
  - 設定が無効なら該当の文は出ない。秒数は介助者の設定に追従する。低い・狭い画面では短い文言になる。
- 見ても分からない、設定に応じた動作は、介助者用メニューの「スキャン」タブで、原因の設定のすぐ下に出る。現在の設定値で出し分け、該当がなければ何も出ない。画面が変わった直後も効く連打無視・押下時間の下限・離して決定の設定があるときは、押しても反応しないことがある旨と、押している間に画面や項目の並びが変わると無効になる旨。聴覚スキャン ON で音声モードが「短く」「全部」のときは、伝達の読み上げは直後の1項目分だけ割り込まれないこと。

## 上級者向けのモールス入力

介助者が設定の「モールス」タブで「モールス入力を使う」をONにすると、ホームの最後に「モールス」が出る。短く押すと短点の・、長く押すと長点の－になり、和文モールスで文字を入力する。境目の秒数は画面に出る。キー / スイッチのほか、画面のボタン以外の場所を押しても同じように入力できる。

- 緊急は **SOS の ・・・ －－－ ・・・ を休まず続けて**打つ。9つ目の押下を離した時点で、待たずにすぐ緊急になる。前に間違えた押下があっても、休まず続ければ緊急になる。既定 1.5 秒の文字の確定時間だけ休むと数え直しになり、文字ごとに休んで打った SOS は緊急にならない。「かぜ」などのように、かなを打った結果が偶然 SOS の並びになるだけでは緊急にしないため
- ・を5つ → 待つとスキャンへ戻る。・を6つ → 待つと1字消す。・－・－・－ → 待つと確定して伝える
- 押下と解放をほぼ同時に送る Bluetooth シャッターでは長押しを区別できず、モールスも SOS も使えない場合がある。その場合はモールスを使わず、スキャンを使う
- 画面の案内の見方: 操作の符号と、時間で自動で起きることが常に表示される。文字が決まるまで・語の区切りまで・何も押さないとスキャンへ戻るまでの時間と、押しっぱなしの無効。秒数は介助者の設定に合わせて変わる。押下時間の下限を設定している場合は「◯秒未満の押下は数えない」も出る

## 介助者の操作

現在地と画面の案内を出す画面上部の案内欄の、右上にある「介助者用」ボタンを通常のクリック/タップで開くと、設定と緊急解除ができる。ボタンの左には、設定した好きな画像が出ることがある。メニューを閉じる「閉じる」ボタンは、どの画面の大きさでも画面の右上にある。「緊急を解除」は緊急中だけ、左右の中央に出る。狭い画面では「閉じる」の下の行に出る。上部のカテゴリタブ「使用準備 / スキャン / 音と振動 / 表示 / フレーズ / モールス / データ / このアプリ」で設定を切り替える。タブが画面に収まらないときは、続きがある側に矢印が出る。フレーズ編集は「フレーズ」、設定の書き出し・取り込みは「データ」、利用ガイドなどのリンク・利用回数・バージョンは「このアプリ」タブにある。**リンク先を開いている間は、本人のスイッチの操作も、画面が消えないようにする働きも効かない。見終わったら必ずアプリの画面に戻る**。ボタンにフォーカスした Enter / Space でも開く。この入口は本人のスキャン決定とは別で、介助者用メニューはタッチで操作するメニュー中のキー入力はメニューを閉じる。例外は、タブにフォーカス中に修飾キーなしで押す ←/→/Home/End、文字を入力する欄での文字入力・編集のキー、スライダーの矢印キー。決定のタイミング・音声モード・振動の強さ・パネルの文字サイズ・明るさのように値を選ぶ設定はラジオボタンで、選んでいる値は丸が塗られて太字になる。フレーズを編集する画面は、パネルの階層を字下げした一覧から選ぶ。並びは、快 の下の 気分、不快、その下の 痛い と その他、要望。

- スキャンタブはスキャン間隔 / 先頭待機 / 連打無視 / 押下時間の下限 / 決定のタイミング / 聴覚スキャン、モールスタブはモールス入力、音と振動タブは音声モード / 振動。先頭待機はスキャン開始時に先頭に留まる秒数で、既定は間隔 1.5 秒のとき 2.0 秒。設定画面に秒数が出る。すでに保存した設定はそのままで、「スキャン」タブの「初期値に戻す」で新しい既定になる。連打無視は 0.1〜3 秒で、0 にはできない。スライダーは左右の矢印で 1 段階ずつ調整でき、端まで来ると外側の矢印は消える
- パネルの文字サイズ: 標準 / 大 / 特大。すぐ下のサンプルで大きさを確かめられる。パネルの文字を、そのパネルに収まる範囲で段階的に大きくする。メッセージ欄の見出しの大きさはこの設定に左右されない。見出しが伸縮すると格子の面積が変わり、結果的にパネルの文字が逆に縮むことがあったため。列数・パネルの配置・大きさといった画面のレイアウト自体は変わらない。選択肢が少ない画面でも、パネルは大きくならず同じ大きさのまま空いたマスが残る。空きマスは選べない。「直前に伝えたこと」やパンくずなどの補助文字は、この設定にかかわらず常に 16px 以上で表示する。この設定ではまだ大きくならない
- 明るさ: ライト / ダーク / OSの設定から選び、既定は OSの設定。画面の明暗を切り替える。「OSの設定」は端末の OS の設定 `prefers-color-scheme` にその場で追従する。周りの明るさを測る機能ではない
- 高コントラスト: ON / OFF。ライト・ダークどちらの表示の上にも重ねて効く。文字と面の明暗差を強め、パネル間の区切り線を太くする
- メニューを開くと最初に出る「使用準備」タブの「画面スリープ防止」の状態表示。このタブに変える設定はない。「有効」なら画面消灯を防げている。「無効」の場合は端末の自動ロックを OFF にする。詳しくは `docs/troubleshooting.md`
- 使用準備タブのアプリのインストール: ブラウザが受け付ける場合は「アプリをインストール」ボタンから端末の確認画面を出せる。iPhone / iPad や Mac の Safari などボタンから出せない場合は、手順が箇条書きで出る。デスクトップの Firefox では、Chrome か Edge で開くよう案内する。インストールした版で開くと「アプリはインストール済みです。」と出る。Android と iOS の実機でのインストールは未確認
- 表示タブの好きな画像: 「画像を選ぶ」で端末の画像を 1 枚選ぶと、本人画面の「介助者用」ボタンの左に表示される。画像を押すと、ボタン以外の場所と同じく黄色のパネルを選ぶ。長辺 480px に縮小して、この端末の中の localStorage の `libra:photo` だけに保存し、外へは送らない。設定の書き出しには含まれない。「画像を消す」か、表示タブの「初期値に戻す」で消える
- 初期値に戻す: スキャン / モールス / 音と振動 / 表示 / フレーズの各タブの末尾にある。そのタブの設定だけを初期値に戻す。1 回目に押すと何が戻るかが出て、もう一度押すと実行する。「やめる」・タブの切替・メニューを閉じるで取りやめになる。緊急状態と本人のスキャンには影響しない
- 「このアプリ」タブ: このガイドを開く「利用ガイド」・ご意見・ご感想の掲示板・作者サイト・フォントのライセンスへのリンク、利用回数、バージョンがある。バージョンは公開版の最後の変更日を日本時間の年月日で示す。利用回数は、本番のサイトで開いたときだけ、起動ごとに 1 回数える。同じ端末の重複は 1 日単位で除かれる。通信できないときは「取得できません」と出るだけで、伝達には影響しない。フォントのライセンスはオフラインでも開ける。ほかのリンクは通信が必要
  - **リンク先を開いている間の注意**: リンクは別のブラウザ画面で開く。開いている間は、本人のスイッチの操作も、画面が消えないようにする働きも効かない。見終わったら、必ずアプリの画面に戻る。インストールした版で「フォントのライセンス」を開いたあとアプリに戻れるかは、特に iOS の実機で未確認
- 緊急表示は、介助者が解除するか、本人が 緊急 → 緊急を解除 → 解除する を選ぶまで残る。緊急警告音は鳴らさない。再読み込み・再起動しても解除まで復元される
- メニュー表示中は本人のスイッチ入力が働かない。以下のいずれでも、その操作自体では何も実行せずメニューが閉じてホーム先頭からスキャンが再開する
  - 無操作のまま 60 秒経過する。延ばせるのはメニュー内のタップだけで、キー入力では延びない。矢印ボタンのタップも延びる。画面には説明の文は出ない。メニューを開いている間はスキャンが止まり、モールス入力が有効ならモールス入力の時間も止まる
  - 本人が誤ってキーを押す。ただし次は閉じない: タブにフォーカス中に修飾キーなしで押す ←/→/Home/End、フレーズ編集の欄と設定データの欄のような文字を入力する欄にフォーカス中の文字入力・Backspace・矢印・Home/End・IME変換中の打鍵、スライダーにフォーカス中の矢印キー。スライダー上で矢印キー型のスイッチを押すと、設定値が静かに変わりうる。どれも60秒タイマーは延ばさない。ラジオボタンやチェックボックスにフォーカスが残っていても、どのキーでも閉じ、値は変わらない。キーがくり返し届くスイッチの押しっぱなしも同じで、値は変わらず、ボタンも実行されない。押したままメニューを開くと、くり返しの打鍵ですぐ閉じる
  - メニュー内の操作は通常の介助者操作として扱われ、閉じない
