# Libra 状態一覧

| 対象 | 利用者に約束する内容 | 外部依存 | 実装状態 | Issue化 |
|---|---|---|---|---|
| 緊急メッセージ | 短い用件を1タップで大きく表示 | なし | 試作済み | 可 |
| ゆっくり伝える | 痛い場所・困りごと・気分を選ぶ | なし | 試作済み | 可 |
| 文字盤 | かな入力の入口 | なし | 試作 | 可 |
| 音声モード | OFF / 効果音 / 短文 / 全文 | Web Speech API | 試作 | 可 |
| 自動スキャン | Space / Enter で決定 | なし | 試作 | 可 |
| Bluetooth ボタン | 外部ボタンで決定 | ブラウザ / OS | 未検証 | 可 |
| フレーズ編集 | 家族・介助者が文言を編集 | localStorage | 未実装 | 可 |
| 介助者確認 | 誤送出前に確認する | なし | 未実装 | 可 |
