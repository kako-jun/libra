# Libra 格子状 UI 規約

Libra は Esuna と同じく「大きな矩形を押す」設計を採用する。ただし Esuna の 9 マス固定レイアウトは採用しない。

## 原則

- タイルは大きく、遠目で読める
- 隙間なしの格子: タイル間の gap・角丸・影は使わない。セルは右+下の細い区切り線
  (トークン `--grid-line`/`--grid-line-width`。高コントラストで太くなる)だけで
  区切り、メッセージ欄・文字盤入力欄も含めて画面全体が一枚の盤に見えるようにする
- 項目数と格子領域の実測サイズ(縦横比)から列数・行数を自動算出し、
  孤立タイルや下部の空白を出さずに格子領域全体をタイルで敷き詰める
  (`computeGridLayout`、目安8項目以内の画面が対象。文字盤等それを超える
  画面、または最小セル寸法を満たす分割が無い画面は、最小タイル高を保って
  スクロールする)。最後の行に空きが出る場合は最後のタイルを横に伸ばして
  埋める(spanは最大2まで)。最小セル寸法(文字サイズに応じて拡大)を下回る
  列数の候補は最初から除外し、極端に細い帯(例: 7列×1行)が選ばれないように
  する。セルの縦横比の評価は `|log(aspect)|`(2倍と0.5倍を対称に同じ悪さとして
  扱う)で行う
- 緊急タイルは赤系のベタ塗り、通常タイルは面の色(塗り分け)で区別する。
  さらに色以外でも判別できるよう、緊急タイルには常時、内側に白系の輪郭
  (色覚特性への配慮)を付ける
- 選択中の自動スキャン対象は、セル内側に収まる(隣のセルへはみ出さない)
  黄色枠 + 面の色変化で示す。黄色単体では白背景等に対するWCAG非テキスト
  コントラスト(3:1)を満たさないため、濃色(または明色、テーマ・タイルの色調に
  応じて自動選択)のアウトラインを重ねた二重枠にしている。隙間なし格子では
  拡大(scale)すると隣のセルと重なるため使わない
- どの画面でもスキャン1周の先頭は「緊急」
- メッセージ表示エリアは常に画面上部に固定する。アプリ名・音声モード・
  スキャン位置などの状態表示は置かない(本人はカーソルの強調で位置が分かる)
- 下位画面へ進むタイルは、ラベル末尾に矢印文字を置かず、右端の山形アイコン
  (インラインSVG)+ 下部の中身の予告(遷移先メニューから自動生成)で示す。
  読み上げはラベルのみで、アイコン・予告は読まない

## 操作

本人の操作はシングルスイッチ自動スキャンのみ（正本: `requirements.md`）。

| 入力                                     | 動作                                         |
| ---------------------------------------- | -------------------------------------------- |
| タップ / 任意キー / Bluetooth シャッター | 現在のスキャン対象を実行（本人の唯一の入力） |
| 介助者ボタン長押し（2 秒）               | 介助者メニュー（設定・緊急解除）             |

以下は開発・介助者向けの補助で、本人の経路には使わない。

| 入力    | 動作                                                                                                                                                                    |
| ------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `1`-`9` | `?dev` 付き URL のときのみ有効。画面上の先頭9タイルを直接実行する（番号表示も `?dev` のときのみ。通常時は数字キーも任意キーと同じ扱いで、現在のスキャン対象を実行する） |

## Esuna との差分

Esuna は視覚障害者向けの一貫操作として 9 マスの意味を固定する。

Libra はベッドサイドで本人と周囲が同時に見るため、タイル数・配置は画面や用途で変えてよい。固定するのは「格子状で押しやすい」「現在のメッセージが大きく見える」という体験である。
