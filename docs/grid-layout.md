# Libra 格子状 UI 規約

Libra は Esuna と同じく「大きな矩形を押す」設計を採用する。ただし Esuna の 9 マス固定レイアウトは採用しない。

## 原則

- タイルは大きく、遠目で読める
- タイル間には十分な余白を置く
- 緊急タイルは赤系、通常タイルは緑系を基本にする
- 選択中の自動スキャン対象は黄色の太いアウトラインで示す
- メッセージ表示エリアは常に画面上部に固定する

## 操作

| 入力 | 動作 |
|---|---|
| タップ | タイルを実行 |
| `1`-`9` | 画面上の先頭9タイルを直接実行 |
| 矢印キー | スキャン対象を移動 |
| `Space` / `Enter` | スキャン対象を実行 |
| `Escape` | 戻る |

## Esuna との差分

Esuna は視覚障害者向けの一貫操作として 9 マスの意味を固定する。

Libra はベッドサイドで本人と周囲が同時に見るため、タイル数・配置は画面や用途で変えてよい。固定するのは「格子状で押しやすい」「現在のメッセージが大きく見える」という体験である。
