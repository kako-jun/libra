# Libra 音声操作

## 音声モード

| モード | 内容 |
|---|---|
| OFF | 読み上げなし |
| 効果音だけ | バイブレーション / 短いフィードバックのみ |
| 短く読む | タイル名や短い確認だけ読む |
| 全部読む | 表示メッセージを全文読む |

## 原則

- 相部屋や夜間を考慮し、デフォルトは OFF
- **例外: 緊急の警告音は音声モードに関係なく鳴らし、介助者の解除まで繰り返す**
- 聴覚スキャン（カーソル移動ごとに項目名を読む）は介助者設定で ON/OFF
- 音声なしでも、画面を見せれば伝わる
- 音声は補助であり、必須経路にしない
