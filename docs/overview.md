# Libra — 概要

`libra` は病棟ベッドサイド向けの超軽量コミュニケーション補助アプリ。

`esuna` が本人ひとりでも成立する娯楽・気分転換のためのアプリであるのに対し、`libra` は患者本人と周囲の人のあいだで意思を伝えるための道具に絞る。

## 立ち位置

- ナースコールの置き換えではない
- 病院全体システムの置き換えでもない
- その手前 / 横に置く
- 家族や介助者が横にいる場面で使う
- スマホやタブレットだけで導入できる

## 基本導線

要件の正本は `requirements.md`。

- 本人はシングルスイッチ自動スキャンだけで操作する
- ホームの巡回順: 緊急 → はい → いいえ → 不快 → 快・要望 → 文字盤
- 設定は介助者が長押しで開き、本人のスキャン巡回には含めない

緊急導線と深い入力導線を混ぜない。どの画面でもスキャン1周の先頭は緊急。

## UI 方針

Esuna のような押しやすい格子状UIを踏襲する。ただし Libra は 9 分割固定ではない。

画面幅や用途に応じてタイル数は変えてよい。重要なのは、遠目でも読める大きさ、押し間違いにくい余白、状態が一目で分かる大きな表示である。
