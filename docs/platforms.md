# Libra — 対応プラットフォーム

Libra はブラウザで動く Web アプリとして設計する。

## 第一対象

- タブレット
- ベッド横の机に立てかけた常設端末
- スマホ

## 入力

- タッチ
- キーボード
- Space / Enter 相当の外部ボタン
- Bluetooth シャッターボタン

## PWA

ホーム画面に追加すると `display: fullscreen`（非対応環境では `standalone`）で起動し、ブラウザの UI が隠れた状態で使える。介助者メニューの「全画面にする」でも同様の状態にできる。

## 常設運用時の端末設定（推奨）

ベッド横に常設し、画面全体を本人のスイッチとして使う想定（`docs/requirements.md` §3, §8）。Libra 自体の機能で対策していることと、端末側で設定してほしいことを分けて書く。

- **端末の自動ロック（画面消灯）は OFF にする**: Libra は起動時に Screen Wake Lock API で画面消灯を防ぎ、タブが再表示されたときも再取得する。ただし OS 側の設定次第では効かない場合があるため、介助者メニューの「画面スリープ防止」表示が有効になっているか確認する。非対応/失敗時はそこに端末側の設定を促す文言が出る
- **常時充電しながら使う**: 画面を常時点灯させ続けるとバッテリー消耗が早い
- **ホーム画面に追加して起動する**: 全画面になり、ブラウザの戻る操作やタブ切り替えなどの誤操作経路を減らせる
- **オフラインでも動く**: Service Worker がアプリ本体（HTML/JS/CSS/フォント/アイコン）を事前キャッシュしているため、ネットワーク断・バックエンド停止でも緊急・はい/いいえ等の伝達は動作を続ける
