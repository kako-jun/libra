# libra

**病棟ベッドサイド向けの、押しやすい格子状コミュニケーション補助アプリ**

`libra` は、患者本人と家族・介助者・看護師のあいだで短い意思を伝えるための超軽量 AAC 補助アプリです。

ナースコールや病院システムの置き換えではありません。その手前や横に置いて、「水がほしい」「痛い」「体の向きを変えたい」「はい」「いいえ」をすばやく伝えるラストワンマイルの道具です。

## 機能

- **本人の入力は2経路だけ** — 任意のキー押下 / Bluetooth シャッター。現在のスキャン対象を実行する1つの「オン」になる。もう1つはパネルの直接タップで、スキャン位置とは無関係に、押したパネルを実行する。パネル・ボタン以外の場所を押すと、キーと同じく黄色のパネルを選ぶ。
- **起動時から常時自動スキャン** — 本人の経路にスキャン開始/停止は置かない。止まると本人は再開できないため。
- **安全の優先順位で並ぶ画面構成** — ホームは先頭が緊急、次が直前の伝達をもう一度伝える「もう一度」。聞き逃されたときに選択をやり直さずに済む。その後に はい・いいえ。通常下位画面は「戻る→緊急」、緊急詳細は「戻る」の次に未選択の詳細候補が並ぶ。自由作文の文字盤は定型プリセットより手前に出さない。
- **押しやすい格子状UI** — Esuna のような押しやすさを保ちつつ、9分割固定にはしない。ホームの全項目と「戻る」には、意味の分かるアイコンを添える。
- **大きな表示** — 選んだ言葉をベッド横から読める大きさで表示。
- **現在地・直前の伝達** — 画面上部は 緊急の表示 → 直前に伝えたこと → 現在地・画面の案内 の順。ホームからの先頭に家のアイコンが付く短いパンくずを常時表示し、現在の画面は画面見出しでも分かる。パンくずの祖先はクリック/タップでその画面へ戻れる。直前に伝えたことの枠は起動時から高さが一定で、長い文も全文を収める。介助者が内容がある方向だけに出る左右の矢印で過去の伝達を振り返れる。伝達は端末のメモリ内だけに最大50件持ち、背景色はその内容の色のままになる。追加の入力や待機は求めない。
- **自動で起きることの常時案内** — 本人画面の下端の固定位置に、見ても分からない暗黙の挙動だけを出す。出すのは緊急中の振動のみ。介助者用メニューは60秒で自動で閉じる。連打無視や押下時間の下限など設定に応じた動作は、介助者用メニュー「スキャン」タブの原因の設定のすぐ下に出す。先頭待機のように画面を見れば分かることは書かない。隠す操作はない。
- **緊急の静かな視覚表示** — 緊急を選ぶと確認なしで赤表示する。警告音は鳴らさず、介助者が解除するか、本人が 緊急 → 緊急を解除 → 解除する を選ぶまで画面上部に表示が残る。それ以外の本人入力では解除されない。緊急は再読み込み・再起動後も、解除されるまで復元される。
- **介助者用メニュー** — 現在地と画面の案内を出す画面上部の案内欄の、右上にある「介助者用」ボタンを通常のクリック/タップで開く。全幅の上部カテゴリタブ「使用準備 / スキャン / 音と振動 / 表示 / フレーズ / モールス / データ / このアプリ」で、選んだカテゴリの設定だけを表示する。タブに続きがあるときは矢印が出る。閉じるはタブの上に常時出て、緊急を解除は緊急中だけ中央に出る。スライダーは左右の矢印で 1 段階ずつ調整できる。使用準備タブではアプリをインストールできる。ボタンから出せない環境は手順を表示する。実機は未確認。「初期値に戻す」はタブごとで、2回押して確認する。フレーズ編集は「フレーズ」、設定の書き出し・取り込みは「データ」、利用ガイドなどのリンク・利用回数・公開版の最後の変更日を示すバージョンは「このアプリ」にある。値を選ぶ設定はラジオボタン。表示タブの好きな画像は「介助者用」ボタンの左に表示でき、端末の中だけに保存する。タブはフォーカス中に修飾キーなしの ←/→/Home/End で移動でき、この打鍵では無操作60秒の自動クローズを延ばさない。フォーカスしたボタンの Enter / Space でも開き、本人のスイッチ入力とは分離する。設定は localStorage に保存。
- **ライト/ダークテーマ** — URLクエリではなく介助者設定で ライト/ダーク/OSの設定 から選び、既定は OSの設定。「OSの設定」は端末の prefers-color-scheme にその場で追従する。高コントラストはどちらのテーマの上にも重ねて効く。パネルの格子は隙間も角丸もない一枚盤で、セル間は細い区切り線だけ。格子は画面ごとに決まる3種類。標準は8セルで、縦長 2列×4行 / 横長 4列×2行。ホームは通常の8項目なら標準と同じ8セルで空きがなく、モールス使用の9項目は10セルで、縦長 2列×5行 / 横長 5列×2行。「はい」「いいえ」はどの画面サイズでも同じ段で隣り合う。文字盤の行段階は15セルで、縦長 3列×5行 / 横長 5列×3行。同じ画面の全ての選択肢は同じ大きさで並ぶ。9項目のホームだけ、下位画面とパネルの大きさが違う。項目が少ないときはパネルを引き延ばさず、余りはスキャン・タップの対象外の空きセルとして残す。フレーズを増やしてセル数を超えた画面だけスクロールする。スキャン対象はセル内側に収まる太い黄色のリングで強調し、文字・予告はリングの内側に置いて隠さない。隣のセルと重ならないよう拡大はしない。
- **音声モード** — OFF / 効果音だけ / 短く読む / 全部読む。
- **Esuna と同じ構成** — frontend / backend / docs / CI / LICENSE の形を揃える。
