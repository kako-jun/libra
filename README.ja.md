# libra

**病棟ベッドサイド向けの、押しやすい格子状コミュニケーション補助アプリ**

`libra` は、患者本人と家族・介助者・看護師のあいだで短い意思を伝えるための超軽量 AAC 補助アプリです。

ナースコールや病院システムの置き換えではありません。その手前や横に置いて、「水がほしい」「痛い」「体の向きを変えたい」「はい」「いいえ」をすばやく伝えるラストワンマイルの道具です。

## 機能

- **本人の入力はシングルスイッチ1種類だけ** — 画面のどこかへのタップ、任意のキー押下（Bluetooth シャッターもキー入力として届く）、Bluetooth シャッター本体、すべて同じ1つの「オン」として扱う。
- **起動時から常時自動スキャン** — 本人の経路にスキャン開始/停止は置かない。止まると本人は再開できないため。
- **安全の優先順位で並ぶ画面構成** — どの画面のスキャン1周も先頭は緊急、下位画面はその直後に戻る。自由作文の文字盤は定型プリセットより手前に出さない。
- **押しやすい格子状UI** — Esuna のような押しやすさを保ちつつ、9分割固定にはしない。
- **大きな表示** — 選んだ言葉をベッド横から読める大きさで表示。
- **緊急警告音** — 緊急を選ぶと確認なしで赤表示し、Web Audio の警告音を音声OFFでも鳴らす。介助者が解除するまで繰り返す。
- **介助者メニュー** — 画面隅ボタンを2秒長押しでスキャン間隔・先頭待機・連打無視・聴覚スキャン・音声モード・緊急解除を設定できる。設定は localStorage に保存。
- **音声モード** — OFF / 効果音だけ / 短く読む / 全部読む。
- **Esuna と同じ構成** — frontend / backend / docs / CI / LICENSE の形を揃える。
