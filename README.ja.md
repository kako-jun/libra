# libra

**病棟ベッドサイド向けの、押しやすい格子状コミュニケーション補助アプリ**

`libra` は、患者本人と家族・介助者・看護師のあいだで短い意思を伝えるための超軽量 AAC 補助アプリです。

ナースコールや病院システムの置き換えではありません。その手前や横に置いて、「水がほしい」「痛い」「体の向きを変えたい」「はい」「いいえ」をすばやく伝えるラストワンマイルの道具です。

## 機能

- **本人の入力は2経路だけ** — 任意のキー押下 / Bluetooth シャッター（現在のスキャン対象を実行する1つの「オン」）と、タイルの直接タップ（押したタイルを実行。スキャン位置とは無関係）。画面の背景へのタップは何も実行しない。
- **起動時から常時自動スキャン** — 本人の経路にスキャン開始/停止は置かない。止まると本人は再開できないため。
- **安全の優先順位で並ぶ画面構成** — ホームは先頭が緊急、次が「もう一度」（直前の伝達をもう一度伝える。聞き逃されたときに選択をやり直さずに済む）、その後に はい・いいえ。通常下位画面は「戻る→緊急」、緊急詳細は「戻る」の次に未選択の詳細候補が並ぶ。自由作文の文字盤は定型プリセットより手前に出さない。
- **押しやすい格子状UI** — Esuna のような押しやすさを保ちつつ、9分割固定にはしない。ホームの全項目と「戻る」には、意味の分かるアイコンを添える。
- **大きな表示** — 選んだ言葉をベッド横から読める大きさで表示。
- **現在地・直前の伝達** — 画面上部は 緊急の表示 → 直前に伝えたこと → 現在地・画面の案内 の順。ホームからの短いパンくず（先頭は家のアイコン付き）を常時表示し、現在の画面は画面見出しでも分かる。パンくずの祖先はクリック/タップでその画面へ戻れる。直前に伝えたことの枠は起動時から高さが一定で、長い文も全文を収める。介助者が左右の矢印（内容がある方向だけに出る）で過去の伝達（端末のメモリ内だけ・最大50件）を振り返れ、背景色はその内容の色のままになる。追加の入力や待機は求めない。
- **自動で起きることの常時案内** — 画面下端（介助者用メニューは上部）の固定位置に、見ても分からない暗黙の挙動だけを出す（本人画面は緊急中の振動のみ、介助者用メニューは60秒自動閉じなど）。連打無視や押下時間の下限など設定に応じた動作は、介助者用メニュー「スキャン」タブの原因の設定のすぐ下に出す。画面を見れば分かること（取り消しの出入り・先頭待機）は書かない。隠す操作はない。
- **緊急の静かな視覚表示** — 緊急を選ぶと確認なしで赤表示する。警告音は鳴らさず、介助者が解除するか、本人が 緊急 → 緊急を解除 → 解除する を選ぶまで画面上部に表示が残る（それ以外の本人入力では解除されない）。緊急は再読み込み・再起動後も、解除されるまで復元される。
- **介助者用メニュー** — 画面上部の案内欄（現在地・画面の案内）の右上にある「介助者用」ボタンを通常のクリック/タップで開く。全幅の上部カテゴリタブ（端末の状態 / スキャン / モールス / 音と振動 / 表示 / フレーズ / データ / このアプリ。続きがあるときは矢印が出る）で、選んだカテゴリの設定だけを表示し、緊急を解除と閉じるはタブの上に常時出る。「初期値に戻す」はタブごと（2回押しで確認）。フレーズ編集は「フレーズ」、設定の書き出し・取り込みは「データ」、使い方・リンク・利用回数・バージョンは「このアプリ」にある。好きな画像（表示タブ）は「介助者用」ボタンの左に表示でき、端末の中だけに保存する。タブはフォーカス中の ←/→/Home/End（修飾キーなし）で移動でき、この打鍵では無操作60秒の自動クローズを延ばさない。フォーカスしたボタンの Enter / Space でも開き、本人のスイッチ入力とは分離する。設定は localStorage に保存。
- **明るい/夜間テーマ** — URLクエリではなく介助者設定(明るい/夜間/自動、既定 自動)。自動は端末の prefers-color-scheme にその場で追従する。高コントラストはどちらのテーマの上にも重ねて効く。タイル格子は隙間なしの一枚盤(角丸なし、セル間は細い区切り線のみ)で、格子は画面ごとに決まる3種類(標準 8セル=縦長 2列×4行 / 横長 4列×2行、ホーム 10セル=縦長 2列×5行 / 横長 5列×2行、文字盤の行段階 15セル=縦長 3列×5行 / 横長 5列×3行)。同じ画面の全ての選択肢は同じ大きさで並び、ホームと下位画面ではタイルの大きさが違う。項目が少ないときはタイルを引き延ばさず、余りは何もない空きセルとして残す(空きセルはスキャン・タップの対象外)。セル数を超えた画面(フレーズを増やした画面)だけスクロールする。スキャン対象はセル内側に収まる太い黄色のリングで強調し、文字・予告はリングの内側に置いて隠さない(隣のセルと重ならないよう拡大はしない)。
- **音声モード** — OFF / 効果音だけ / 短く読む / 全部読む。
- **Esuna と同じ構成** — frontend / backend / docs / CI / LICENSE の形を揃える。
