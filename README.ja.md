# libra

**病棟ベッドサイド向けの、押しやすい格子状コミュニケーション補助アプリ**

`libra` は、患者本人と家族・介助者・看護師のあいだで短い意思を伝えるための超軽量 AAC 補助アプリです。

ナースコールや病院システムの置き換えではありません。その手前や横に置いて、「水がほしい」「痛い」「体の向きを変えたい」「はい」「いいえ」をすばやく伝えるラストワンマイルの道具です。

## 機能

- **本人の入力は2経路だけ** — 任意のキー押下 / Bluetooth シャッター（現在のスキャン対象を実行する1つの「オン」）と、タイルの直接タップ（押したタイルを実行。スキャン位置とは無関係）。画面の背景へのタップは何も実行しない。
- **起動時から常時自動スキャン** — 本人の経路にスキャン開始/停止は置かない。止まると本人は再開できないため。
- **安全の優先順位で並ぶ画面構成** — ホームは先頭が緊急、通常下位画面は「戻る→緊急」、緊急詳細は「戻る」の次に未選択の詳細候補が並ぶ。自由作文の文字盤は定型プリセットより手前に出さない。
- **押しやすい格子状UI** — Esuna のような押しやすさを保ちつつ、9分割固定にはしない。
- **大きな表示** — 選んだ言葉をベッド横から読める大きさで表示。
- **現在地** — ホームからの短いパンくずを常時表示し、現在の画面は画面見出しでも分かる。パンくずの祖先はクリック/タップでその画面へ戻れる。通常の伝達・緊急詳細とは別領域で、追加の入力や待機も求めない。
- **自動で起きることの常時案内** — 画面下端（介助者メニューは上部）の固定位置に、見ても分からない暗黙の挙動だけを出す（本人画面は緊急中の振動のみ、介助者メニューは60秒自動閉じなど）。連打無視や押下時間の下限など設定に応じた動作は、介助者メニューの「状態」タブ「いまの動作」に出す。画面を見れば分かること（取り消しの出入り・先頭待機）は書かない。隠す操作はない。
- **緊急の静かな視覚表示** — 緊急を選ぶと確認なしで赤表示する。警告音は鳴らさず、介助者が解除するまで画面上部に表示が残る。緊急は再読み込み・再起動後も、介助者が解除するまで復元される。
- **介助者メニュー** — 画面上部の案内欄（現在地・画面の案内）の右上にある「介助者用」ボタンを通常のクリック/タップで開く。全幅の上部カテゴリタブ（状態 / スキャン / 入力方式 / フィードバック / 表示 / フレーズ / データ。スマホは横スクロール、広い画面は均等配置）で、選んだカテゴリの設定だけを表示し、緊急解除と閉じるはタブの上に常時出る。フレーズ編集は「フレーズ」、設定の書き出し・取り込み・既定に戻す（どちらも2回押しで確認）は「データ」にある。タブはフォーカス中の ←/→/Home/End（修飾キーなし）で移動でき、この打鍵では無操作60秒の自動クローズを延ばさない。フォーカスしたボタンの Enter / Space でも開き、本人のスイッチ入力とは分離する。設定は localStorage に保存。
- **明るい/夜間テーマ** — URLクエリではなく介助者設定(明るい/夜間/自動、既定 自動)。自動は端末の prefers-color-scheme にその場で追従する。高コントラストはどちらのテーマの上にも重ねて効く。タイル格子は隙間なしの一枚盤(角丸なし、セル間は細い区切り線のみ)で、画面の向きだけで決まる固定格子(縦長 2列×4行 / 横長 4列×2行)を全画面で共有し、全ての選択肢を同じ大きさで並べる。項目が少ないときはタイルを引き延ばさず、余りは何もない空きセルとして残す(空きセルはスキャン・タップの対象外)。スキャン対象はセル内側に収まる太い黄色のリングで強調し、文字・予告はリングの内側に置いて隠さない(隣のセルと重ならないよう拡大はしない)。
- **音声モード** — OFF / 効果音だけ / 短く読む / 全部読む。
- **Esuna と同じ構成** — frontend / backend / docs / CI / LICENSE の形を揃える。
