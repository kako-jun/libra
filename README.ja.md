# libra

**病棟ベッドサイド向けの、押しやすい格子状コミュニケーション補助アプリ**

`libra` は、患者本人と家族・介助者・看護師のあいだで短い意思を伝えるための超軽量 AAC 補助アプリです。

ナースコールや病院システムの置き換えではありません。その手前や横に置いて、「水がほしい」「痛い」「体の向きを変えたい」「はい」「いいえ」をすばやく伝えるラストワンマイルの道具です。

## 機能

- **本人の入力は2経路だけ** — 任意のキー押下 / Bluetooth シャッター（現在のスキャン対象を実行する1つの「オン」）と、タイルの直接タップ（押したタイルを実行。スキャン位置とは無関係）。画面の背景へのタップは何も実行しない。
- **起動時から常時自動スキャン** — 本人の経路にスキャン開始/停止は置かない。止まると本人は再開できないため。
- **安全の優先順位で並ぶ画面構成** — ホームは先頭が緊急、通常下位画面は「戻る→緊急」、緊急詳細は「戻る」の次に未選択の詳細候補が並ぶ。自由作文の文字盤は定型プリセットより手前に出さない。
- **押しやすい格子状UI** — Esuna のような押しやすさを保ちつつ、9分割固定にはしない。
- **大きな表示** — 選んだ言葉をベッド横から読める大きさで表示。
- **現在地と選択確認** — ホームからの短いパンくずを常時表示し、最後に採用した画面遷移や文字を別領域で確認できる。通常の伝達・緊急詳細とは重複させず、追加の入力や待機も求めない。
- **自動で起きることの常時案内** — 画面下端（介助者メニューは上部）の固定位置に、取り消しの自動表示・緊急中の振動・連打無視や押下時間の下限・先頭待機・メニューの60秒自動閉じなど、暗黙の挙動を理由つきで常に出す。隠す操作はなく、該当する状況・設定のときだけ出る。
- **緊急の静かな視覚表示** — 緊急を選ぶと確認なしで赤表示する。警告音は鳴らさず、介助者が解除するまで画面上部に表示が残る。緊急は再読み込み・再起動後も、介助者が解除するまで復元される。
- **介助者メニュー** — メッセージ欄右上の「介助者用」ボタンを通常のクリック/タップで開く。全幅の上部カテゴリタブ（状態 / スキャン / 入力方式 / フィードバック / 表示 / フレーズ / データ。スマホは横スクロール、広い画面は均等配置）で、選んだカテゴリの設定だけを表示し、緊急解除と閉じるはタブの上に常時出る。フレーズ編集は「フレーズ」、設定の書き出し・取り込み・既定に戻す（どちらも2回押しで確認）は「データ」にある。タブはフォーカス中の ←/→/Home/End（修飾キーなし）で移動でき、この打鍵では無操作60秒の自動クローズを延ばさない。フォーカスしたボタンの Enter / Space でも開き、本人のスイッチ入力とは分離する。設定は localStorage に保存。
- **明るい/夜間テーマ** — URLクエリではなく介助者設定(明るい/夜間/自動、既定 自動)。自動は端末の prefers-color-scheme にその場で追従する。高コントラストはどちらのテーマの上にも重ねて効く。タイル格子は隙間なしの一枚盤(角丸なし、セル間は細い区切り線のみ)で、項目数と格子領域自体の縦横比から列数・行数を自動算出し、常に画面いっぱいに敷き詰める(空きセル・下部の空白なし)。スキャン対象はセル内側に収まる太い黄色のリングで強調する(隣のセルと重ならないよう拡大はしない)。
- **音声モード** — OFF / 効果音だけ / 短く読む / 全部読む。
- **Esuna と同じ構成** — frontend / backend / docs / CI / LICENSE の形を揃える。

## プロトタイプの範囲

| 領域                                                               | 状態                                                                     |
| ------------------------------------------------------------------ | ------------------------------------------------------------------------ |
| シングルスイッチ自動スキャン(キー/BTシャッター) + タイル直接タップ | 実装済み                                                                 |
| 安全の優先順位に沿った画面構成(ホーム:緊急、通常下位:戻る→緊急)    | 実装済み                                                                 |
| 緊急（静かな視覚表示）                                             | 実装済み                                                                 |
| はい / いいえ                                                      | 実装済み                                                                 |
| 不快 / 快・要望 / 痛い場所                                         | 実装済み                                                                 |
| 文字盤                                                             | 簡易版（清音10字の入口のみ。2段階の全かな盤は別Issueで予定）             |
| 音声モード                                                         | 実装済み                                                                 |
| 介助者メニュー(設定)                                               | 実装済み                                                                 |
| オフライン動作(Service Worker precache)                            | 実装済み                                                                 |
| 画面スリープ防止(Screen Wake Lock)                                 | 実装済み                                                                 |
| 定型文のカスタム編集                                               | 実装済み                                                                 |
| 外部スイッチのペアリング                                           | 未着手（キーイベントとしての受け取りのみ。ネイティブペアリングは未実装） |
